# 工程取舍说明

## 1. 时间对齐

流量、密度、脂肪和固形物测量粒度不同。系统把密度/脂肪/固形物点样视为“持续到下一个同指标点样”的半开区间，然后与流量区间求交集：

- 质量流量：`M = Σ q_m Δt`
- 体积流量：`M = Σ q_V ρ Δt`
- 脂肪质量：`M_f = Σ q_m x_f Δt`，体积流量时再乘密度
- 干基脂肪：仅当同一时间片存在湿基固形物比例 `s` 时计算 `x_f,wet = x_f,dry · s`

重叠观测在写入时拒绝；流量缺口不插值，只报告未覆盖时长。量程切换由相邻、非重叠且 `range_code` 不同的记录表达，并逐段积分。

## 2. 守恒方程与成环

每条物流有两个窗口总量变量：质量 `m_e`、脂肪质量 `f_e`。每个库存罐另有初始/终止质量和脂肪质量。对所有非 source/sink 节点建立：

```text
I_n + Σ_in m_e - Σ_out m_e - F_n = 0
I_f,n + Σ_in f_e - Σ_out f_e - F_f,n = 0
```

source/sink 不强行平衡，因为其边界之外不在模型范围内。罐底旧料不是经验分摊项，而是 `I_n / I_f,n`；跨批送出和回流不是特殊修正项，而是普通有向边。因此回流环和跨批环天然出现在同一线性矩阵中。

## 3. 可辨识性与欠定处理

求解前把守恒矩阵和已有测量的单位矩阵堆叠为 `[A; I_measured]`，用数值秩与变量数比较：

- 满秩：允许执行带非负边界的加权最小二乘；
- 欠定：通过组合搜索找出最小补测变量集合，并对候选变量做线性规划，给出非负可行区间（无上界时明确返回 `max: null`，不捏造工程上限）；
- 欠定时只返回报告，不生成“唯一调整图”，也不把未知回流流量默认为零。

测量误差按一个标准差加权。相对不确定度转换为绝对值；95%扩展不确定度除以 1.96。零或极小不确定度设置下限，避免除零。

## 4. 冻结、过期与迟到样

入队时生成规范化 JSON 快照，包含稳定窗口、拓扑、测量、算法版本和输入摘要 SHA-256。Worker 只使用快照，不读取任务提交后的当前值。

稳定窗口、拓扑或测量变化会提升批段版本。Worker 在完成时再次比较 `job.input_version` 与当前段版本：

- 一致：写入成功/欠定结果；
- 不一致：标记 `superseded`，不写 `result`，当前图 API 也不会返回它。

这样慢任务或冻结后晚到的实验室样都不能覆盖当前图。晚到样进入新的版本后，需要重新入队。

## 5. 签署

签署只允许针对“成功且当前版本”的作业。签署记录冻结输入摘要、算法版本、工程师、备注和 HMAC 风格签名（SHA-256，截断 32 位）。生产环境必须通过 `FAT_SIGNING_SECRET` 设置独立密钥。

## 6. 明确不做的事

平台不计算推荐回配比例，不输出控制动作、阀门位置、泵频率或设备设定值；Plotly 图和表格仅用于工程核算审计。
